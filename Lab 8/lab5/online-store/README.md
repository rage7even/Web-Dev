# Lab 5 Online Store

Angular storefront for the Lab 5 assignment. The project extends the previous store with category-based browsing, parent-child communication, likes, deletion, and shared product actions.

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Included features

- 4 categories and 20 products with real Kaspi product links
- `AppComponent → ProductListComponent → ProductItemComponent`
- `input()` and `output()` based component communication
- Like and delete interactions with immediate UI updates
- Responsive grid layout and modern minimalist styling
