Starting My Programming Journey

Date: January 20, 2026

Today I took my very first steps into the world of programming. I began learningHTML and CSS, and it amazed me how simple tags can create the structure of a webpage. Styling with CSS feels like giving life to plain text — suddenly everything looks more organized and readable. It’s exciting to see how quickly small changes can transform a page. This is just the beginning, but I already feel motivated to keep going.

Playing With Styles

Date: January 22, 2026

After getting comfortable with basic HTML, I explored CSS text properties. Changing fonts, line spacing, and colors made my blog look much more personal. I especially enjoyed experimenting with font-family and line-height to make the text easier to read. It feels rewarding to see my blog evolve from a plain page into something that reflects my personality. Next, I want to try adding images and maybe even some interactive elements with JavaScript

First Steps with JavaScript

Date: January 25, 2026

This week I wrote my very first lines of JavaScript. At first, it felt intimidating compared to HTML and CSS, but once I saw how a simple script could make my page interactive, I was hooked. I created a button that changes the background color when clicked, and it felt like magic. Learning how logic and events work opened a whole new world of possibilities. My next goal is to build a small interactive project — maybe a to‑do list or a simple game.
